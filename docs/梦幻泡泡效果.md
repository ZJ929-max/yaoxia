# 梦幻泡泡效果（梦幻泡泡 / Dreamy Bubble）

> 状态：**已转正为正式视觉特性**，不是缺陷。
> 位置：`ui/Glass.kt`、`ui/FloatingTabBar.kt`
> 相关提交：`685638a`、`8e6fae7`

## 它是什么

界面里的"玻璃"层（底部胶囊导航栏、卡片、设置区块）**不做真实的光学折射**，
而是由四层叠加出来的质感：

1. **底色**：`surface` 42% 透明度，让背后的内容保留可见度；
2. **边缘高光**：`Highlight.Default`，沿形状内缘一圈柔光；
3. **内外阴影**：`Shadow` + `InnerShadow`，制造厚度与"鼓起"的错觉；
4. **背景光斑**：`SandboxSurface` 里三团低透明度色斑（紫 `#6D5BFF`、青 `#00D4B8`、橙 `#FF9F0A`），
   透过半透明层形成缓慢晕开的色雾。

合起来就是一层"肥皂泡"式的质感：**透、亮边、有厚度、随背景色变化**。
因此正式命名为**梦幻泡泡效果**。

## 为什么不是液态玻璃

`Backdrop 2.0.1` 的 `lens()` / `blur()` 依赖把 `RenderEffect` 挂到录制层上。
在本项目的 Compose 运行时与该设备（Android 16 / SDK 36）组合下，
`GraphicsLayer.renderEffect` 没有真正作用到录制层：

```
I YaoxiaGlass: content layer recorded 1220.0x2712.0     ← 层录制正常
I YaoxiaGlass: sdk=36 renderEffect=true runtimeShader=true  ← 能力检测通过
```

即：能力齐备、层非空、形状正确（`com.kyant.shapes.Capsule`），但折射不出现。
与其继续和库的渲染管线纠缠，不如把这个**稳定可复现的观感**固化下来。

## 设计约束（改代码时请注意）

- 光斑透明度上限 0.3；再高会盖住深色主题的文字对比度；
- 玻璃层底色透明度 0.42；低于 0.3 时文字可读性下降；
- 高光与内阴影是"泡泡感"的主要来源，**不要为了性能删掉**；
- 若将来 `Backdrop` 修复了 `renderEffect`，可在此之上叠加真实折射，
  但必须保留高光/阴影，否则会退化成普通毛玻璃。

## 验收

- 深色模式下，列表文字与玻璃层对比度 ≥ 4.5:1；
- 导航栏浮在列表之上时，背景色斑能透出并随滚动位置改变；
- 关闭「液态玻璃」开关后，回落到 Material/Miuix 实心卡片，不残留光斑。
